# QRCODE generator

![Python Version](https://img.shields.io/badge/Python-3.12-blue?logo=python&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-lightgrey)

Gerador de QR Code via python utilizando da biblioteca [qrcode](https://pypi.org/project/qrcode/).

# Como executar

## 1. Clonar o repositório

Abra o **CMD**, PowerShell ou terminal e execute:

```bash
git clone https://github.com/ArthurGeraldo/qrcore-gen.git
```

Entre na pasta do projeto:

```bash
cd qrcore-gen
```

## 2. Instalar as dependências

Instale todos os pacotes necessários com:

```bash
pip install -r requirements.txt
```

## 3. Executar o programa

Após instalar as dependências, execute:

```bash
python main.py
```

## Execução rápida

Se o Git e o Python já estiverem instalados, você pode executar:

```bash
git clone https://github.com/ArthurGeraldo/qrcore-gen.git
cd qrcore-gen
pip install -r requirements.txt
python main.py
```

## Requisitos

* **Python 3.12**
* **Git**
* Conexão com a internet para instalar as dependências
